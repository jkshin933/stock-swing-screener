# 4-Core Stock Screener v2.3

S&P 500과 Nasdaq-100 종목을 대상으로 네 가지 기술적 셋업을 탐색하고, 각 셋업의 품질을 0~100점으로 평가하는 Python 스크리너입니다.

RS Rating은 후보군 진입 조건으로만 사용합니다. 최종 S/A/B 등급은 RS가 아니라 거래량 감소, 상대강도 개선, 패턴 구조와 정밀도를 합산한 **Setup Quality Score**로 결정됩니다.

## 주요 기능

- S&P 500 + Nasdaq-100 통합 종목 검색
- 중복 티커 자동 제거
- SPY 대비 20거래일 상대강도 변화 측정
- 20EMA, VCP, B&R, MTF 셋업 탐색
- 한 종목에서 여러 셋업이 발견되면 모두 저장
- 가장 높은 점수의 셋업을 대표 전략으로 선택
- S/A/B 등급 및 전략별 세부 측정값 출력
- 이전 셋업을 최대 2일간 보존하는 TTL 상태 관리
- 엔진 버전이 다른 과거 상태 자동 제외

## 설치

Python 3.10 이상을 권장합니다.

```bash
pip install pandas yfinance lxml html5lib
```

## 실행

```bash
python screener.py
```

실행 위치에 다음 파일이 생성되거나 갱신됩니다.

- `dashboard_data.json`: 대시보드와 외부 프로그램에서 사용할 검색 결과
- `state.json`: 셋업 상태와 TTL 유지를 위한 내부 상태

두 파일의 위치를 바꾸려면 `screener.py` 상단의 `STATE_FILE`, `DASHBOARD_FILE` 값을 수정하면 됩니다.

## 공통 후보 조건

아래 조건을 모두 만족해야 네 가지 전략 검사를 시작합니다.

| 조건 | 기준 |
|---|---:|
| 주가 | $10 이상 |
| 최근 50일 평균 거래대금 | $50M 이상 |
| RS Rating | 70 이상 |
| 최소 가격 데이터 | 230거래일 |

평균 거래대금은 `종가 × 거래량`의 50일 이동평균입니다. RS Rating은 전체 검색 종목의 3개월·12개월 가중 수익률을 비교한 백분위입니다.

## 전략 조건

### 1. 20EMA Pullback

상승 중인 20EMA 부근까지 조정받은 뒤 종가가 EMA 위를 지키는 종목을 찾습니다.

- 현재가가 SMA50 위
- EMA20이 5거래일 전보다 상승
- 당일 저가가 EMA20 대비 -3%~+2%
- 종가가 EMA20 이상
- RVOL3 ≤ 1.00

구조 점수는 당일 캔들의 종가 위치와 EMA 접촉 정밀도로 평가합니다.

### 2. VCP

변동성이 단계적으로 줄어들면서 최근 피벗 부근에 위치한 종목을 찾습니다.

- `Price > SMA50 > SMA200`
- 최근 변동성이 이전 구간 대비 두 단계 연속 8% 이상 감소
- 최근 5일 가격 범위 ≤ 7.5%
- 현재가가 직전 20일 피벗의 -10%~+2.5%
- RVOL3 ≤ 0.80

구조 점수는 5일 범위의 타이트함과 피벗 근접도로 평가합니다.

### 3. Breakout & Retest (B&R)

장기 저항을 거래량과 함께 돌파한 뒤 피벗을 다시 테스트하는 종목을 찾습니다.

- 최근 3~30거래일 사이 직전 200일 고점 돌파
- 돌파 전 종가가 피벗의 101% 이하
- 돌파일 종가가 피벗의 101.5% 초과
- 돌파일 거래량이 직전 50일 평균의 1.5배 이상
- 돌파 뒤 피벗 대비 4% 이상 상승
- 고점에서 현재가까지 3% 이상 조정
- 당일 저가가 피벗의 -3%~+2%
- 종가가 피벗의 99% 이상을 유지
- 현재가가 SMA200 위
- RVOL3 ≤ 0.65

구조 점수는 당일 저가와 돌파 피벗 사이의 거리로 평가합니다.

### 4. Momentum Tight Flag (MTF)

강한 선행 상승 뒤 고점 부근에서 거래량이 줄고 가격 범위가 압축된 종목을 찾습니다.

- **RS Rating > 80**
- 최근 40거래일의 시간순 최대 상승률 ≥ 18%
- `Price > EMA20 > SMA50`
- 최근 10일 전체 가격 범위 ≤ 18%
- 현재가가 최근 40일 고점에서 15% 이내
- RVOL3 ≤ 1.10

최대 상승률은 최근 40일의 각 시점까지 발생한 저점 이후 상승률을 계산하므로, 고점이 저점보다 먼저 나온 경우를 잘못된 상승으로 취급하지 않습니다.

## 점수 체계

각 셋업의 총점은 100점입니다. v2.3 보정판에서는 각 전략의 실제 Gate 경계와 점수 경계를 일치시켜, 현실적인 우수 셋업도 S등급에 도달할 수 있도록 조정했습니다.

| 구성 요소 | 최대 점수 |
|---|---:|
| 3일 상대 거래량 감소 | 25 |
| SPY 대비 20일 상대강도 개선 | 15 |
| 전략별 구조와 정밀도 | 60 |
| 합계 | 100 |

점수는 구간 내에서 연속적으로 계산됩니다. 조건을 통과했다고 고정 점수를 주지 않으며, 더 타이트하고 정밀한 구조일수록 높은 점수를 받습니다. 거래량 점수의 하한은 각 전략의 RVOL Gate와 같고, 상대강도선은 소폭 하락부터 강한 개선까지 연속 평가합니다.

MTF의 60점 구조점수는 다음처럼 나뉩니다.

| MTF 구조 항목 | 최대 점수 |
|---|---:|
| 10일 Flag Tightness | 25 |
| 40일 고점 근접도 | 15 |
| 40일 선행 상승 강도 | 10 |
| Price와 EMA20 간 추세 간격 | 5 |
| EMA20과 SMA50 간 추세 간격 | 5 |

## 등급

| 등급 | Setup Quality Score | 의미 |
|---|---:|---|
| S | 85~100 | 최상위 셋업 |
| A | 70~84 | 우수 셋업 |
| B | 60~69 | Watch 후보 |
| 제외 | 0~59 | 결과에 표시하지 않음 |

**등급은 RS Rating으로 정하지 않습니다.** 예를 들어 RS 82인 종목도 셋업 점수가 88이면 S등급이며, RS 95인 종목도 셋업 점수가 65이면 B등급입니다.

## 출력 데이터 예시

```json
{
  "state": "setup",
  "symbol": "NVDA",
  "strategy": "MTF",
  "score": 88,
  "grade": "S",
  "setups": {
    "MTF": 88,
    "VCP": 74
  },
  "setup_meta": {
    "MTF": {
      "max_runup_40d_pct": 31.4,
      "flag_range_10d_pct": 7.82,
      "drawdown_from_40d_high_pct": 3.15,
      "mtf_rs_threshold": 80
    }
  },
  "price": 182.35,
  "rvol": 0.61,
  "rs_rating": 93.2,
  "mcap": 4450.0,
  "engine_version": "2.3"
}
```

실제 값은 실행 시점의 시장 데이터에 따라 달라집니다.

## 상태 유지

- 오늘 셋업이 사라져도 이전 `setup` 상태를 최대 2일간 유지합니다.
- `action`, `working`, `failed` 같은 기존 라이프사이클 상태도 정해진 규칙에 따라 보존합니다.
- `engine_version`이 `2.3`이 아닌 과거 상태는 불러오지 않습니다.
- `state.json`을 삭제하면 상태 이력 없이 새로 시작합니다.

## 주의사항

- Wikipedia와 Yahoo Finance에서 데이터를 가져오므로 인터넷 연결이 필요합니다.
- 데이터 누락, 티커 변경, 공급자 지연으로 일부 종목이 제외될 수 있습니다.
- 시장 휴장일에는 마지막 거래일 데이터를 사용합니다.
- 이 프로그램은 기술적 후보를 정렬하는 도구이며 매수·매도 추천이나 수익 보장을 제공하지 않습니다.

## 새로고침과 새 스캔

두 동작은 서로 다릅니다.

- **결과 새로고침:** 캐시를 사용하지 않고 최신 `dashboard_data.json`을 다시 읽습니다.
- **새 스캔 실행:** GitHub Actions의 `scan.yml`을 열어 `Run workflow`로 Python 스크리너를 실행합니다.

GitHub Pages는 정적 사이트이므로 인증 없이 브라우저에서 GitHub Actions를 직접 시작할 수 없습니다. 저장소의 `.github/workflows/scan.yml`에 제공된 워크플로를 넣으면 수동 실행이 가능하고, 미국 시장 마감 후 평일 자동 실행도 예약됩니다. 워크플로가 끝난 다음 대시보드에서 **결과 새로고침**을 누르면 새로운 결과가 표시됩니다.
