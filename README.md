# 4-Core Stock Screener v2.5

S&P 500과 Nasdaq-100 종목을 대상으로 네 가지 기술적 셋업을 탐색하고, 각 셋업의 품질을 0~100점으로 평가하는 Python 스크리너입니다.

RS Rating은 후보군 진입 조건으로만 사용합니다. 최종 S/A/B 등급은 RS가 아니라 거래량 감소, 상대강도 개선, 패턴 구조와 정밀도를 합산한 **Setup Quality Score**로 결정됩니다.

## 주요 기능

- S&P 500 + Nasdaq-100 통합 종목 검색
- 중복 티커 자동 제거
- SPY 대비 20거래일 상대강도 변화 측정
- 20EMA, VCP, B&R, MTF 셋업 탐색
- 한 종목에서 여러 셋업이 발견되면 모두 저장
- 가장 높은 점수의 셋업을 대표 전략으로 선택
- S/A/B 등급 및 전략별 세부 측정값 출력
- 이전 셋업을 최대 2일간 보존하는 TTL 상태 관리
- 엔진 버전이 다른 과거 상태 자동 제외
- Setup → Action → Working/Failed 라이프사이클 자동 전환

## 설치

Python 3.10 이상을 권장합니다.

```bash
pip install pandas yfinance lxml html5lib
```

## 실행

```bash
python screener.py
```

실행 위치에 다음 파일이 생성되거나 갱신됩니다.

- `dashboard_data.json`: 대시보드와 외부 프로그램에서 사용할 검색 결과
- `state.json`: 셋업 상태와 TTL 유지를 위한 내부 상태

두 파일의 위치를 바꾸려면 `screener.py` 상단의 `STATE_FILE`, `DASHBOARD_FILE` 값을 수정하면 됩니다.

## 공통 후보 조건

아래 조건을 모두 만족해야 네 가지 전략 검사를 시작합니다.

| 조건 | 기준 |
|---|---:|
| 주가 | $10 이상 |
| 최근 50일 평균 거래대금 | $50M 이상 |
| RS Rating | 70 이상 |
| 최소 가격 데이터 | 230거래일 |

평균 거래대금은 `종가 × 거래량`의 50일 이동평균입니다. RS Rating은 전체 검색 종목의 3개월·12개월 가중 수익률을 비교한 백분위입니다.

## 전략 조건

### 1. 20EMA Pullback

상승 중인 20EMA 부근까지 조정받은 뒤 종가가 EMA 위를 지키는 종목을 찾습니다.

- 현재가가 SMA50 위
- EMA20이 5거래일 전보다 상승
- 당일 저가가 EMA20 대비 -3%~+2%
- 종가가 EMA20 이상
- RVOL3 ≤ 1.00

구조 점수는 당일 캔들의 종가 위치와 EMA 접촉 정밀도로 평가합니다.

### 2. VCP

변동성이 단계적으로 줄어들면서 최근 피벗 부근에 위치한 종목을 찾습니다.

- `Price > SMA50 > SMA200`
- 최근 변동성이 이전 구간 대비 두 단계 연속 8% 이상 감소
- 최근 5일 가격 범위 ≤ 7.5%
- 현재가가 직전 20일 피벗의 -10%~+2.5%
- RVOL3 ≤ 0.80

구조 점수는 5일 범위의 타이트함과 피벗 근접도로 평가합니다.

### 3. Breakout & Retest (B&R)

장기 저항을 거래량과 함께 돌파한 뒤 피벗을 다시 테스트하는 종목을 찾습니다.

- 최근 3~30거래일 사이 직전 200일 고점 돌파
- 돌파 전 종가가 피벗의 101% 이하
- 돌파일 종가가 피벗의 101.5% 초과
- 돌파일 거래량이 직전 50일 평균의 1.5배 이상
- 돌파 뒤 피벗 대비 4% 이상 상승
- 고점에서 현재가까지 3% 이상 조정
- 당일 저가가 피벗의 -3%~+2%
- 종가가 피벗의 99% 이상을 유지
- 현재가가 SMA200 위
- RVOL3 ≤ 0.65

구조 점수는 당일 저가와 돌파 피벗 사이의 거리로 평가합니다.

### 4. Momentum Tight Flag (MTF)

강한 선행 상승 뒤 고점 부근에서 거래량이 줄고 가격 범위가 압축된 종목을 찾습니다.

- **RS Rating > 80**
- 최근 40거래일의 시간순 최대 상승률 ≥ 18%
- `Price > EMA20 > SMA50`
- 최근 10일 전체 가격 범위 ≤ 18%
- 현재가가 최근 40일 고점에서 15% 이내
- RVOL3 ≤ 1.10

최대 상승률은 최근 40일의 각 시점까지 발생한 저점 이후 상승률을 계산하므로, 고점이 저점보다 먼저 나온 경우를 잘못된 상승으로 취급하지 않습니다.

## 점수 체계

각 셋업의 총점은 100점입니다. v2.5에서는 소수 지표만으로 95~100점에 도달하지 못하도록 만점 기준을 강화하고 구조점수를 여러 독립 요소로 분해했습니다.

| 구성 요소 | 최대 점수 |
|---|---:|
| 3일 상대 거래량 감소 | 20 |
| SPY 대비 20일 상대강도 개선 | 10 |
| 전략별 구조와 정밀도 | 70 |
| 합계 | 100 |

점수는 구간 내에서 연속적으로 계산됩니다. RVOL3 만점 기준은 0.35, RS Line 개선 만점 기준은 SPY 대비 +6%로 강화했습니다. 각 결과의 `setup_meta → 전략 → score_components`에서 항목별 점수를 확인할 수 있습니다.

MTF의 70점 구조점수는 다음처럼 나뉩니다.

| MTF 구조 항목 | 최대 점수 |
|---|---:|
| 10일 Flag Tightness | 25 |
| 40일 고점 근접도 | 15 |
| 40일 선행 상승 강도 | 15 |
| Price와 EMA20 간 적정 간격 | 8 |
| EMA20과 SMA50 간 추세 간격 | 7 |

B&R의 70점 구조점수는 다음처럼 나뉩니다.

| B&R 구조 항목 | 최대 점수 |
|---|---:|
| Retest Precision | 20 |
| Breakout Volume | 12 |
| Breakout Close Quality | 10 |
| Post-breakout Separation | 8 |
| Pullback Quality | 8 |
| Retest Candle Quality | 7 |
| Breakout Age | 5 |

## 등급

| 등급 | Setup Quality Score | 의미 |
|---|---:|---|
| S | 85~100 | 최상위 셋업 |
| A | 70~84 | 우수 셋업 |
| B | 60~69 | Watch 후보 |
| 제외 | 0~59 | 결과에 표시하지 않음 |

**등급은 RS Rating으로 정하지 않습니다.** 예를 들어 RS 82인 종목도 셋업 점수가 88이면 S등급이며, RS 95인 종목도 셋업 점수가 65이면 B등급입니다.

## 구조 대기와 당장 매수

새로 발견된 패턴은 먼저 `setup`(구조 대기)으로 저장됩니다. S/A등급 셋업이 전략별 진입가격을 종가로 돌파하고 당일 거래량 확인 조건까지 만족하면 `action`(당장 매수)으로 자동 승격됩니다. B등급은 Watch 후보이므로 Action으로 승격하지 않습니다.

| 전략 | Action 진입 트리거 | 당일 거래량 확인 | 구조 손절가 |
|---|---|---:|---|
| 20EMA | 셋업 캔들 고가 +0.2% | RVOL ≥ 0.90 | 셋업 저가와 EMA20 하단 중 낮은 값 아래 |
| VCP | 피벗 +0.5% 종가 돌파 | RVOL ≥ 1.20 | 최근 5일 저가 아래 |
| B&R | 리테스트 캔들 고가 +0.2% | RVOL ≥ 0.90 | 고정 피벗 -3.5% |
| MTF | 직전 10일 고가 +0.5% 종가 돌파 | RVOL ≥ 1.20 | Flag 저가 또는 EMA20 구조 하단 |

여기서 Action용 RVOL은 최근 3일 평균이 아니라 **당일 거래량 ÷ 직전 50일 평균 거래량**입니다. 돌파 당일의 실제 수급 확인에 사용합니다.

상태 흐름은 다음과 같습니다.

```text
S/A Setup
  ├─ 진입 트리거 + 거래량 확인 → Action
  ├─ 구조 손절가 이탈         → Failed
  └─ 패턴 소멸 후 2일 초과    → 제거

Action
  ├─ 2일 초과 또는 진입가 +5% 초과 → Working
  └─ 구조 손절가 이탈               → Failed
```

Action은 진입 가능 구간을 의미하며 2일 동안 유지됩니다. 이미 진입가격보다 5% 넘게 상승했거나 2일이 지나면 추세 진행 상태인 `working`으로 바뀌어 당장 매수 목록에서 제외됩니다. `failed`는 3일간 내부 상태에 보존됩니다.

## 출력 데이터 예시

```json
{
  "state": "setup",
  "symbol": "NVDA",
  "strategy": "MTF",
  "score": 88,
  "grade": "S",
  "setups": {
    "MTF": 88,
    "VCP": 74
  },
  "setup_meta": {
    "MTF": {
      "max_runup_40d_pct": 31.4,
      "flag_range_10d_pct": 7.82,
      "drawdown_from_40d_high_pct": 3.15,
      "mtf_rs_threshold": 80
    }
  },
  "price": 182.35,
  "rvol": 0.61,
  "rs_rating": 93.2,
  "mcap": 4450.0,
    "engine_version": "2.5"
}
```

실제 값은 실행 시점의 시장 데이터에 따라 달라집니다.

## 상태 유지

- 오늘 셋업이 사라져도 이전 `setup` 상태를 최대 2일간 유지합니다.
- `action`, `working`, `failed` 같은 기존 라이프사이클 상태도 정해진 규칙에 따라 보존합니다.
- `engine_version`이 `2.5`가 아닌 과거 상태는 불러오지 않습니다.
- `state.json`을 삭제하면 상태 이력 없이 새로 시작합니다.

## 결과 로드와 새 스캔

결과 페이지는 열릴 때마다 캐시를 사용하지 않고 최신 `dashboard_data.json`을 자동으로 읽습니다. 별도의 결과 새로고침 버튼은 없습니다. 자동 스캔이 끝난 뒤 브라우저 페이지를 다시 열거나 일반 새로고침하면 새 결과가 표시됩니다.

**새 스캔 실행**은 GitHub Actions의 `scan.yml`을 열어 `Run workflow`로 Python 스크리너를 실행하는 기능입니다. 저장소의 `.github/workflows/scan.yml`에 제공된 워크플로를 넣으면 수동 실행이 가능하고, 평일 `23:17 UTC`에 자동 실행됩니다. GitHub Actions의 정각 혼잡을 피하기 위해 17분에 예약했습니다.

카드 이미지와 `Open Finviz Chart` 버튼은 Finviz 종목 페이지로 연결됩니다. 가격 데이터 다운로드는 Yahoo Finance를 계속 사용하지만 무거운 Yahoo 대화형 차트 페이지는 열지 않습니다.

결과 페이지 상단에는 모든 S급 종목을 `Score / Ticker / Strategy / Status` 순서로 보여주는 표가 있습니다. `ACTION`과 `SETUP`을 구분하며 Action을 먼저 배치합니다. Copy 버튼으로 같은 네 개 열을 탭 구분 텍스트로 복사할 수 있습니다.
